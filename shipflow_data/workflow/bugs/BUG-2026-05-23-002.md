# Bug Record: BUG-2026-05-23-002

## Summary

- Title: Termux bootstrap fails when local dotfiles files are dirty
- Current status: `fixed-pending-verify`
- Severity: `medium`
- Owner: dianedef
- Next command: `curl -fsSL https://winflowz.com/termux-script | sh`

## Reproduction

- Preconditions:
  - `~/dotfiles` already exists in Termux.
  - At least one tracked file, such as `termux.sh`, has local modifications.
- Steps:
  1. Run `curl -fsSL https://winflowz.com/termux-script | sh`.
  2. Let the bootstrap update the existing `~/dotfiles` repository.

## Expected Behavior

- The bootstrap should preserve local modifications safely and continue updating the managed dotfiles checkout.

## Observed Behavior

- The bootstrap fails during `git pull --ff-only` with `Your local changes to the following files would be overwritten by merge`.

## Evidence

- User log from 2026-05-23 showing `termux.sh` blocked the merge from `b4c4376` to `6e74b34`.
