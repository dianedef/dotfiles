# Bug Record: BUG-2026-05-23-001

## Summary

- Title: Termux leaves a black unused area above the keyboard
- Current status: `fixed-pending-verify`
- Severity: `medium`
- Owner: dianedef
- Next command: `curl -fsSL https://winflowz.com/termux-script | sh`

## Reproduction

- Preconditions:
  - Fresh Termux installation on Android.
  - Dotfiles installed through the Termux installer.
- Steps:
  1. Run `curl -fsSL https://winflowz.com/termux-script | sh`.
  2. Open Termux with the software keyboard visible.
  3. Scroll or type in the terminal.

## Expected Behavior

- The terminal should use the full visible area above the Android keyboard.

## Observed Behavior

- The keyboard uses the bottom third, the terminal uses only the top third, and a black unused middle third remains inaccessible.

## Evidence

- User report from 2026-05-23.
- `termux/termux.properties` set both `fullscreen = true` and `use-fullscreen-workaround = true`.
