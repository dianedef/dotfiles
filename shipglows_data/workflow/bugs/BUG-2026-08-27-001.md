# Bug Record: BUG-2026-08-27-001

## Summary

- Current status: `closed`
- Expected: the Windows profile installs without optional native-toolchain failures and Avante receives a verified native Codex ACP runtime.
- Observed: Avante uses `make`, Lazy attempts a CMake-only fzf build, and the installer has no Windows Codex ACP lifecycle.

## Reproduction

1. Install the Windows Dotfiles profile without CMake/C++ build tools.
2. Start Neovim and inspect Lazy plugin state.
3. Resolve the configured Avante Codex ACP command.

## Expected Behavior

- Avante uses its official Windows build path.
- Telescope core remains healthy when fzf-native prerequisites are absent.
- The installer pins ACP 0.16.0, installs its optional native win32 package, verifies it, and keeps dry-run/check idempotent.

## Observed Behavior

- Native build commands fail and Codex ACP is unavailable.
