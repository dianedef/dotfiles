# Bug Record: BUG-2026-07-13-002

## Summary

- Title: Avante leaves native Codex ACP processes orphaned after stopping its Node wrapper
- Current status: `fixed-pending-verify`
- Severity: `high`
- Owner: Diane
- Next command: `/103-sg-verify BUG-2026-07-13-002`

## Reproduction

- Preconditions:
  - Avante uses its ACP `codex` provider.
  - The provider command resolves to the npm JavaScript launcher.
- Steps:
  1. Start an Avante Codex ACP request.
  2. Stop the request or exit Neovim cleanly.
  3. Inspect the remaining native `codex-acp` processes.

## Expected Behavior

- Avante owns the process it launches and stops it during `:AvanteStop` or `VimLeavePre` cleanup.
- Repeated Mail Intelligence analyses do not accumulate resident ACP processes.

## Observed Behavior

- Avante terminates the direct Node wrapper, but its native child is reparented to PID 1 and remains resident.
- Six observed launch times produced twelve persistent native processes.

## Evidence

- Installed Avante transport calls `process:kill()` only on its direct child.
- Installed `codex-acp.js` uses synchronous child spawning without forwarding termination signals.
- Process inspection on 2026-07-13 found twelve native instances with PPID 1.
- No email content, token, credential, or private payload was captured.
