# Bug Record: BUG-2026-08-09-001

## Summary

A fresh Linux user-local installation could abort while sourcing the Neovim shell integration, then report tools installed under user-local paths as missing. A system Node.js 24/Corepack installation could also leave pnpm unavailable to a non-root user while the installer continued as if the required Node tools were optional.

## Root Causes

- `nvim/aliases.sh` expanded an unset `PROMPT_COMMAND` under the installer's `set -u` contract.
- The sourced Neovim scripts overwrote the installer's global `SCRIPT_DIR`, redirecting later Ranger synchronization to `nvim/ranger`.
- `run_health_check` did not prepend `~/.local/bin` and `PNPM_HOME` before resolving tools.
- The health contract still expected the retired npm-global path, required optional GitHub authentication, and required Starship to be a symlink even though the installer copies the selected config.
- Corepack could be present without exposing a usable non-root pnpm command; failure skipped required packages and still returned success.

## Fix

- Made shell integration safe with unset Bash/Zsh variables and isolated its internal path variables.
- Evaluated health checks with the user-local PATH, accepted a managed regular Starship config, checked PNPM_HOME, and made authentication warnings non-fatal.
- Added a user-local npm fallback for pnpm, executed package-manager commands from a readable HOME, and made missing pnpm fatal when required Node tools are selected.
- Updated automatic ShipGlows cloning to `commandglows/shipglows` and migrated legacy checkout paths.

## Verification

- Automated regression, Codex ACP, symlink-safety, Windows contract, and Bash syntax checks passed.
- On a disposable Ubuntu 24.04 x86_64 VM with Node.js 24, a fresh non-root install exited `0`, installed `mcpc` and the native Codex ACP runtime, cloned `~/shipglows`, and linked Ranger from the correct source.
- The immediately following `install.sh --check` exited `0` with `All checks passed!`; unauthenticated GitHub and Doppler remained optional warnings.
