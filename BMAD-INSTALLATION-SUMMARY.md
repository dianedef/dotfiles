## ❓ Common Questions

### Q: Do I need to use BMAD for everything?
**A:** No! BMAD is a tool to help structure your work. Use it when it's helpful, skip it when it's not.

### Q: Which agent should I use?
**A:** Start with BMad Master if unsure. It will guide you to the right agent.

### Q: Can I customize the agents?
**A:** Yes! Edit files in `_bmad/_config/agents/` to customize personalities and behaviors.

### Q: What if an agent gives wrong advice?
**A:** Agents are AI assistants, not perfect. Use your judgment and iterate.

### Q: How do I update BMAD?
**A:** Run `npx bmad-method@alpha install` again. Your customizations are preserved.
